# Triage Labels

The engineering skills use five canonical triage roles. This repository uses the canonical names directly.

- `needs-triage`: a maintainer needs to evaluate the issue
- `needs-info`: waiting for more information from the reporter
- `ready-for-agent`: fully specified and ready for an autonomous agent
- `ready-for-human`: requires human implementation or judgment
- `wontfix`: will not be actioned

When a skill refers to a triage role, apply the corresponding label above.

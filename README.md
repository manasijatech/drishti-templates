# Drishti Templates

Open-source reference projects for building Indian-equities research,
monitoring, and event-driven workflows with [Drishti](https://drishti.manasija.in).
Drishti is an Indian stock market API and MCP server that provides structured
company context, filings, announcements, earnings, conference calls, news, and
market events for developer applications and AI agents.

## Included templates

| Template | What it demonstrates |
| --- | --- |
| [`chat-drishti-mcp`](./chat-drishti-mcp) | An AI chat application that uses Drishti MCP for Indian-equity research. |
| [`corporate-action-lifecycle-monitor`](./corporate-action-lifecycle-monitor) | Filing-linked corporate-action lifecycle reconstruction and live updates. |
| [`indian-earnings-monitor`](./indian-earnings-monitor) | A local monitor for earnings, news, and conference calls. |
| [`order-win-tracker`](./order-win-tracker) | Typed ingestion of exchange-reported order-win announcements. |

Each template has its own setup instructions, environment variables, and scope.
They are research and information tools, not investment advice or trading
recommendations.

## Start building

Read the [Drishti API documentation](https://developers.manasija.in/docs),
follow the [Drishti MCP guide](https://drishti.manasija.in/docs/guides/drishti-mcp),
and [create an API key](https://platform.manasija.in/) when the selected template
requires authenticated data access.
